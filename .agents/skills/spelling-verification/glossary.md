# 綴り統一ガロア（正統綴りの参照）

本作『幻想再帰のアリュージョニスト』wiki で**頻繁に混入する綴り間違い**に対処するための参照。
コードポイント単位の厳密検査は `scripts/check_spelling.py` が行います（こちらを手動で写すと
逆に誤りを導入するため、このファイルは「方針・一覧」専用にする）。

## 1. 何が間違えやすいか（疑義文字ペア）

| 見た目 | コードポイントA | コードポイントB | 影響例 |
|---|---|---|---|
| ア | U+30A2（標準） | U+30AD / U+30AF | 「アキラ」vs「アクラ」 |
| る | U+308B（小文字） | U+308D（大文字） | 「きぐみ魔女」の small-る |
| ュ | U+30E5（小文字） | U+30F5（大文字） | イュレイド の small-ユ |
| ォ | U+30C7（小文字） | U+30F7（大文字） | イェレイド の small-オ |
| ー | U+30FC（全角） | U+FF70（半角） | 半角/全角長音の混在 |

これらは**目視では区別不可**。必ず `check_spelling.py` でコードポイント確認する。

## 2. 監視すべき名称一覧（感嘆・要検証あり）

| 名称（読み方針） | 注意点 |
|---|---|
| きぐみ魔女（赤い髪の魔女） | 「ぐみ」は **small-る(U+308B)**。raw ファイル名 `003_きぐみ魔女_01.md` と一致させる |
| アクラ（アキラくん／隻腕義手の青年） | 主読みは **アクラ(U+30AF系)**。源 p180 は「アキラ」とも読む → **要検証** |
| 品森晶（アキラ） | 主人公。名称内「アキラ」= U+30AD。若年者「アクラ」との同一性は **要検証**（断定しない） |
| イュレイド（イェレイド） | small-ユ(U+30E5)/small-オ(U+30C7) を維持 |
| アズーリア / エスフェイル / カイン / キール / テール / トッド / マフス / マーネロア / ガドール /ウルヲーラ | 小文字カナ・長音の混入に注意 |

> この表は「方針」です。各名称の**正確なコードポイント**は `check_spelling.py` の出力または
> 既存ファイルを実物の根拠として確認してください。本表を写して正統値にするのは避ける。

## 3. プロジェクトの判断（既決定／要検証）

- **きぐみ魔女**：small-る で統一（raw ファイル名が根拠）。
- **青年の呼称**：主読み「アクラ」を維持。源原文と既存表記が異なる場合（アキラ／アクラ）は、
  **改名せず【要検証】として記録のみ**。勝手に統一しない。
- **品森晶（アキラ）＝ アクラ の同一性**：**要検証**。断定しない・事実ページに混入させない。

## 4. 使い方

```powershell
# 全体検査（コードポイント単位で疑義文字を報告＋同一ファイル内の分裂を強調）
python .agents/skills/spelling-verification/scripts/check_spelling.py .

# 特定ディレクトリ（例：新規キャラページ生成後）
python .agents/skills/spelling-verification/scripts/check_spelling.py wiki/characters
```

出力の「**要注意**」セクションで、同一ファイル内で見た目が同じ文字が複数コードポイントで
出現している箇所を特定できる。そこが綴り不整合の候補。
