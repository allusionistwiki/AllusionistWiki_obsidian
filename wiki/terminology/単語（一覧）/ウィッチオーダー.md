# ウィッチオーダー

- **初出**: 断章8-6（p.4133）
- **種別**: 魔導書・制御盤

## 概要

紀元槍の制御盤、魔導書【神々と128人の魔法使いたち】が過去の賢人を参照して力を引き出すシステム（p.4133）。百二十二番目の賢人、ロザンディン教授——「我こそはキュトスの姉妹を掌握する配列者なり」（p.4134）。

## 九義肢

ウィッチオーダー最強の形態は九人の姉を模した九義肢（p.4134）。定説とは異なった解釈の『キュトスの姉妹論』——地上にとって、そして槍神教にとって都合の良い形になるように配慮された『偉大なる槍神に侍る九天使』の名（p.4135）。

| 義肢 | 名称 | 機能 |
|---|---|---|
| 第一 | 【ヘリステラ・アラインメント】 | 槍神を運ぶ炎と雷の車輪（p.4135） |
| 第二 | 【エトラメトラトン】 | 槍神の足場とされる浮遊機雷（p.4135） |
| 第三 | 【ディアシェンカ】 | 槍神の賜り物である煌めく呪宝石弾（p.4135） |
| 第四 | 【カチャルマリーナ】 | 槍神に捧げる聖歌である呪文の群れ（p.4135） |
| 第五 | 【ヴァイオレットシャンズ】 | 槍神の召使い、自律機動型攻撃端末（p.4135） |
| 第六 | 【エルザノエル】 | トリシューラ十三歳の狙撃が撃墜（p.4135） |
| 第七 | 【ビェークレット】 | 槍神のために我が身を炎の中へと投げ入れた火炎（p.4135） |
| 第八 | 【ラクルルルアルル】 | 槍神の頭髪たる単分子カッター（p.4135） |
| 第九 | 【シャルロッテネイス】 | 槍神の吐息とされる大気制御機能による大規模な【空圧】（p.4135） |

## 封印

三ヶ月以来、他の八つの封印された機能が解放されたことはない（p.4134）。断章8-6では第五の封印（冥界の権能を司る）が不完全に解除される（p.4159）。
