# 割れた窓理論（Broken Windows Theory）とフリーライダー

> **allusions/Literature/L_External/（核心層：引喩・思想リソース別ページ）。** 原典の説明は正確に、本作への当てはめは解釈として明示。確度ラベル付き。

## 原典の説明
- **割れた窓理論（Broken Windows Theory）**：1982年、社会学者**ジェームズ・Q・ウィルソン**と経済学者**ゲルト・ヘルスマン**が『The New York Times』に寄稿した論文で提唱された犯罪学・都市政策の理論。
  - **核心**：「割れた窓を放置すれば、他の窓も割られていく」。軽微な犯罪・無秩序（graffiti、酔い潰れ、放火）を放置すると、それが**さらに重大な犯罪を誘発する**という仮説。
  - **応用**：1990年代のニューヨーク市（ブルームバーグ以前、ダニエル・パットノウスキー警察局長）の「ゼロトレランス（ゼロ・トレランス）政策」の根拠となった。
  - **批判**：因果関係の過大評価・人種差別との結びつき・「秩序」の定義の恣意性などが指摘される。
- **フリーライダー問題（Free Rider Problem）**：経済学・公共財理論の概念。公共財（安全・秩序・社会）の維持に**貢献しない者（フリーライダー）**が、貢献者の負担を無償で享受する問題。公共財の供給不足を招く。
  - 本作では「フリーライダーを許すな」というスローガンとして登場（p.476）。

## 本作での使われ方
- **第011話（炎は黄金を証明する）p.476**：アキラの元世界（転生保険社会）の「正しさ」の象徴として、無数のスローガンが「ノイズ」として列挙される。
  - 「『お互いが配慮し合う、住みよい街づくりを』『だれもが納得できる、美しい社会に』『**割れた窓を放置してはならない**』『**フリーライダーを許すな**』『子供たちが安心して成長できる国を作ろう』無数のノイズ。**正しさという樹脂を固めて成型**。モデルは豊かな現実。」
  - 割れた窓理論・フリーライダー問題は、**「正しさ」という樹脂で成型された社会の規範**として機能。しかしアキラにとってそれは「無数のノイズ」——**規範がノイズに堕した世界**の描写。
  - 「正しさという樹脂を固めて成型」——規範が**樹脂（樹脂＝プラスチック）のように硬直化**した社会。割れた窓理論が「正しさ」の象徴として機能しつつ、同時に**硬直した社会の象徴**でもある。
- **p.476**：「五十六億七千万年後に来たる**救世トリクルダウン**。優しくて柔らかな虐殺の文法。仮構した問題の最終的解決。存在しない衝突の解消。異常はすべて処理。社会の完全なる正常化。」——**トリクルダウン経済学**（富が上から下へ滴り落ちるという経済政策）が「救世」として転倒。優しさと虐殺が同居する「文法」。
