# 言震（ワードクェイク・言語の崩壊）

> **allusions/Literature/L_External/（核心層：引喩・言語思想リソース別ページ）。** 原典の説明は正確に、本作への当てはめは解釈として明示。確度ラベル付き。

## 原典の説明
- **言語の崩壊（linguistic collapse / language breakdown）**：言語思想・SFの反復主題。
  - **バベルの塔（創世記11章）**：神が**言語を乱し**、人類が互いの言葉を失う——**「言葉の喪失」**の原型神話。
  - **SF・サイバーパンク**：言語の破綻・意味の崩壊を**「言語災害」**として描く伝統（ウィリアム・ギブスン『ニューロマンサー』の言語的混沌、ハル・クラーク『エターナル・フリーダム』の言語的暴動など）。
  - **言語哲学**：ウィトゲンシュタインの「言語ゲーム」の崩壊、デリダの**差延**（意味の固定の不可能性）が極限に達した状態。
- **本作での位置づけ**：**禁呪の代償**として、**「世界の言語そのものが一瞬崩壊する」**事象。

## 本作での使われ方
- **CH0050**（pp.2162–2169、幕間題『言震（ワードクェイク）』）：
  - ハルベルト（ヴァージリア）が禁呪**【創造の光よ】（ブリアー）**を行使し、運命と事実を書き換えた**代償**。
  - **神々の図書館（イルディアンサ）**の機能が一瞬停滞し、**北ドラトリアで言語の崩壊**が起こる。
  - **デモの暴発・暴動・死者**を生み、ドラトリアは**槍神教圏から脱退**を宣言する。
  - 「**言葉は混沌の中に消えていく**」——言語の喪失が**政治的・社会的秩序の崩壊**を招く。
  - 「**言震**」は、**「言葉の地震」**（word + quake）という造語で、**言語の崩壊が物理的災害（地震）と同型の破壊力を持つ**ことを示す。
- **CH0043**（pp.1934）：言震（ワードクェイク）の初出。「**言語汚染災害。言葉が衝突し、意思が混沌に飲み込まれる。最大の言震は地上と地獄を分かつ大戦争の切っ掛け**」。
- **解釈**：
  - 言震は**バベルの塔の逆転**——バベルは**「神が言語を乱した」**（受動的・神の裁き）だが、言震は**「禁呪（人間の呪術）が言語を崩壊させた」**（能動的・人間の代償）。
  - **バベルの塔**（CH0005）が**「言語の分裂の起源」**を説明する神話であるのに対し、**言震**は**「言語の分裂の再発」**——**「絶対言語（単一の言葉）が崩壊し、多様な言葉が混沌に落ちる」**事象。
  - 本作の**「絶対言語」**（ハルベルトの目的）は、**バベル以前の単一の言葉**の再生を目指す。言震は、**絶対言語の不可能性**（差延の宿命）を**物理的災害として実装**したものである。
  - 「**ちっぽけな反動のおまじない**」という描写は、**禁呪の代償が「世界の終焉」と比較して「安上がり」**であることを示し、**「祈りの価値」（CH0049 ０－４）**の主題と接続する。
