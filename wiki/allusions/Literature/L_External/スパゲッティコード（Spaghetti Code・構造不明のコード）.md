# スパゲッティコード（Spaghetti Code・構造不明のコード）

> **allusions/Literature/L_External/（核心層：引喩・実在の技術用語リソース別ページ）。** 原典の説明は正確に、本作への当てはめは解釈として明示。確度ラベル付き。

## 原典の説明
- **スパゲッティコード（spaghetti code）**：**ソフトウェア開発の用語**。**制御フローが複雑に絡み合い、構造が不明瞭で追跡困難なコード**を指す。**スパゲッティ（意匠が絡み合った麺）**に喩える。
- **由来**：**1968年**、**メトロポリタン・ライフ保険会社**のエンジニア**トーマス・クーン（Thomas G. Kuhn）**が**「スパゲッティコード」**という語を初めて使ったとされる（**「スパゲッティ・コード」**）。**GOTO文**の多用が**制御フローの複雑化**を招くことを問題視した文脈。
- **対義語**：**構造化プログラミング**（**構造化されたコード**）。**GOTO文の排除**・**モジュール化**・**関数化**が**スパゲッティコードの解消**を目的とする。
- **象徴**：**「構造が分からない」**・**「何で動いてるのか分からない」**・**「追跡困難」**。

## 本作での使われ方
- **第098話（p.4544）**：**パーンがカーティスの呪文を見て「構造が分からない、何でこれで動いてるんだっ」と言う**——**呪文の構造を「スパゲッティコード」とルビ付きで呼ぶ**。
  - **原文**：**「【墓の下の穢れ】」「だが、カーティスが唱える『言語魔術』は理屈も何もない極めて非効率的なまじないだ。灰色をした文字列の網を漆黒の靄がすり抜けていく。『くそっ、夜の民の触手呪文！ 構造が分からない、何でこれで動いてるんだっ』」**（**ルビ：スパゲッティコード**）。
  - **呪文＝コード**：**「夜の民の触手呪文」**が**「理屈も何もない極めて非効率的なまじない」**として**「構造が分からない」**——**呪文の構造が「スパゲッティコード」**に喩えられる。
  - **構造的機能**：**「呪文」が「コード」に転写**される。**「構造が分からない呪文」が「スパゲッティコード」に転写**される。**呪術体系がソフトウェア構造に喩え**られる。
- **確度**：**【確定】**——「スパゲッティコード」の語が原文にルビとして明示（p.4544）。**呪文＝コードの接続**は主題的接続（ルビの選択が意図的）。
