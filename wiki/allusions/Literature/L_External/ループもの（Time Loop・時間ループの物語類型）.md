# ループもの（Time Loop・時間ループの物語類型）

> **allusions/Literature/L_External/（核心層：引喩・物語類型・メタリソース別ページ）。** 原典の説明は正確に、本作への当てはめは解釈として明示。確度ラベル付き。

## 原典の説明
- **ループもの（time loop / 時間ループ）**：物語の類型。主人公が同じ時間・同じ出来事を何度も繰り返す構造。「失敗→死→リセット→再挑戦」の反復。「死んだら最初からやり直し」のゲーム的構造。
- **代表的な作品**：『ビル・アンド・テッドのタイムマシン』（1989）、『Steins;Gate』（2009–）、『Re:ゼロから始める異世界生活』（2012–）。
- **シジフォスとの接続**：「同じ人生を無限に反復する」＝ニーチェの永遠回帰＝シジフォスの永遠の反復。「ループもの」はシジフォスの神話を「ゲーム的構造」に転写した類型。

## 本作での使われ方
- **第093話（p.4383）**：アキラがルウテトの無限転生を「ループもの」と命名。
  - 原文：「つまりループものという奴ですね。得意分野です」（p.4383）——アキラがルウテトの「何度も何度も繰り返した火竜殺しの旅」を「ループもの」と命名。「得意分野です」＝アキラの前世（転生者）が「ループもの」の構造に精通していることを示唆。
  - ルウテトの反復：「私は何度も何度も繰り返してきました。終わりの無い、火竜殺しの旅を」（p.4382）——「第九階層の火竜に焼かれました。第八階層では巨人族との戦争で……第七階層では松明が切れて……第六階層の大魔将戦は何度やり直したことか」（p.4382）。
  - ゲーム的構造：「失敗すれば最初からやり直しになるタイプのダンジョン探索ゲームのような」（p.4383）——「コルセスカが好きなやつ」（p.4383）。
  - メタ的露出：「あっ、今のゲーム知識は私じゃないです！そういうの全く知りません！近頃の若い子のことなんてわからないです！私は大人の女ですから！」（p.4384）——ルウテトが「ゲーム知識」を口にしたことに慌てる＝「前世（コルセスカ）」の知識が現世に漏れていることをメタ的に露出。
- **構造的機能**：「ループもの」＝「シジフォスの永遠の反復」のゲーム的転写。ch006（明晰夢の「死んでは繰り返し」）のシジフォス構造が、ここでは「ループもの」という類型名で明示。「転生者がループを好む」のメタ的逆説——「コルセスカが好きなやつ」＝「転生（ループ）を好む転生者」。
- **第113話（pp.5015, 5025）**：**サリアとオルヴァの時間遡行戦**。
  - **七回の試行**：「とりあえず七回試したけど。うん、やっぱ最速で駆けつければこのタイミングで割り込んで面倒なカシュラムを処理できる」（p.5015）。
  - **繰り返す円環**：「互いが互いを殺し、そこで見せた切り札を罠として次の周回で奇襲を仕掛ける。繰り返す円環」（p.5025）。
  - **ループ能力の優位性**：「ループ能力の優位性は突き詰めれば情報の格差だ。時間遡行者が対決すれば、自然と情報の隠匿やブラフ合戦といった心理性に発展する」（p.5022）。
  - **構造的機能（ch113）**：時間遡行戦の「失敗→死→リセット→再挑戦」の反復構造が、ここでは「七回試した」「繰り返す円環」として明示。

## 解釈（本作への当てはめ）
- 「ループもの」「得意分野です」「ダンジョン探索ゲーム」「今のゲーム知識は私じゃないです」の語が原文に明示（pp.4382–4384）。【確定】
- 時間ループの物語類型との対応は主題的接続（「失敗→死→リセット→再挑戦」の反復構造が同一）。【相当有力】
- 前世知識の漏出（「ゲーム知識は私じゃない」）はメタフィクションの再帰構造（[[捏造された過去と信用できない語り手（メタフィクションの再帰構造）]] の系譜）。【相当有力】
